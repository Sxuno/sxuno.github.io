DisplaySubsystem

Description

UE5 GameInstanceSubsystem for cross display playercontroller data transfere in local shared world state.

Features

datafrom GameInstance to blueprint Display Informations and opperations. GameInstance as worldstate across XDisplay

Preformance

possible preformance matrix for an instance actor manager to extend PCG with LoD per Display without drawing it twice

Specifications

Allowing to use multi display with different world views and state with an instance spawner improves preformance in an pcg distance lod system which supports nanite and instancing. possible shadow density improvments and allows for GPU driven HLSL instance drawing distance based.
