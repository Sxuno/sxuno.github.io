WebGPU Engine

Description

An Javascript Engine which uses Webgpu, it is an datadriven engine which is build for CDN data delivery to offer

local development in file context
shared matrix screendata
exploration of possible content delivery optimizations
exploration of possible CDN delivery of scenedata
exploration of possible kioskmode for local presentation networks

defered renderpiplines in place to batch instances for eg.

Features

Multicanvas support through custom html tags,
partial Multiscene canvas swapchain integration,
partial datadriven buffer creation,
planned for dynamic htmltag engine bridge

Preformance

static rendering with inital buffer load log Tagparsing through string parsing to avoid eval SoA Buffercache reflects different scenes partial bached drawcalls for backfaceculling nLight support through uniform meta buffer

Specifications

Handels data through blender export to *.js parsing system
with option of appending multiple exports to view in taged canvas.
